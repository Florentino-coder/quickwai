# QuickReply (prototype)

เครื่องมือช่วยแอดมิน LINE OA ตอบลูกค้าด้วยข้อความและรูปที่เตรียมไว้ ประกอบด้วยสองส่วน

- `desktop/` โปรแกรม Windows (Electron): เก็บชุด Reply, Hotkey, หน้าค้นหาด่วน, วางข้อความและรูปลงหน้าต่างแชท
- `extension/` Chrome extension: อ่านชื่อลูกค้าจากโน้ตในหน้า `chat.line.biz` แล้วส่งให้โปรแกรมผ่าน `http://127.0.0.1:38457`

## เริ่มใช้งาน

```bash
npm install
npm start
```

จากนั้นกด "วิธีติดตั้ง Extension" ที่มุมล่างขวาของโปรแกรม แล้วทำตามขั้นตอน

## วิธีใช้

- `Ctrl + Space` เปิดหน้าค้นหาด่วน พิมพ์ค้นหา แล้วกด `Enter` เพื่อวาง
- `Shift + Enter` เลือกรูปก่อนวาง, `Ctrl + 1-9` เลือกรายการตามลำดับ
- Hotkey ของแต่ละ Reply ทำงานเฉพาะตอนแท็บแชท LINE OA อยู่ด้านหน้า
- ใส่ `{ชื่อ}` ในข้อความ โปรแกรมจะแทนด้วยชื่อจากโน้ต ถ้าไม่พบชื่อจะถามก่อนวาง
- โปรแกรมวางข้อความให้ แต่ไม่กดส่ง แอดมินตรวจแล้วกด Enter เอง

## กฎการจับชื่อ

อ่านเฉพาะคำที่ตามหลัง "ชื่อ" ในโน้ต เช่น `ชื่อ มายด์`, `ชื่อ: มายด์`, `ชื่อเล่น มายด์`
ข้าม `ชื่อบัญชี`, `ชื่อผู้ใช้`, `ชื่อไลน์` ดูกรณีทดสอบใน `test/shared.test.js`

## ข้อมูล

ชุด Reply และรูปเก็บใน `%APPDATA%\quickreply` (`quickreply.json` และโฟลเดอร์ `images`)
รุ่นนี้เก็บในเครื่องเดียว ยังไม่มี server กลาง

## โค้ดใช้งาน

โปรแกรมถามโค้ดใช้งานตอนเปิดครั้งแรก และเมื่อโค้ดหมดอายุ การตรวจโค้ดทำในเครื่อง ไม่ใช้อินเทอร์เน็ต

ผู้ดูแลออกโค้ดด้วยคำสั่งนี้ (ต้องมีไฟล์ `license-private.pem`)

```bash
node tools/license.js issue --name "สมชาย" --days 30
```

เพิ่ม `--machine รหัสเครื่อง` เพื่อให้โค้ดใช้ได้เครื่องเดียว รหัสเครื่องแสดงในหน้าใส่โค้ด

`license-private.pem` คือกุญแจออกโค้ด ห้ามส่งให้ใครและห้ามขึ้น GitHub (อยู่ใน `.gitignore` แล้ว)
ถ้าไฟล์หาย ต้องสร้างกุญแจใหม่ด้วย `node tools/license.js keygen` และโค้ดเก่าทั้งหมดจะใช้ไม่ได้

## ส่งต่อชุด Reply

ปุ่ม "ส่งออก" สร้างไฟล์ `.qrpack` ไฟล์เดียว รวมข้อความ Hotkey และรูป ส่งให้คนอื่นทางไหนก็ได้
ปุ่ม "นำเข้า" เลือกได้ว่าจะรวมกับของเดิมหรือแทนที่ทั้งหมด

## ออกโค้ดแบบไม่ใช้คำสั่ง

เปิดไฟล์ `tools/issuer.html` ใน Chrome เลือกไฟล์ `license-private.pem` ใส่ชื่อและจำนวนวัน แล้วกด "ออกโค้ด"
หน้านี้ทำงานในเครื่อง ไม่ใช้อินเทอร์เน็ต

## อัปเดต

โปรแกรมตรวจอัปเดตหลังเปิด 1 นาที และทุก 24 ชั่วโมง หรือกดเลขเวอร์ชันที่มุมล่างขวาเพื่อตรวจทันที
การตรวจหนึ่งครั้งโหลดไฟล์ `updates/latest.json` (ไม่ถึง 1 KB) ถ้ามีเวอร์ชันใหม่จึงโหลดไฟล์อัปเดต (ราว 30 KB)
ไฟล์อัปเดตถูกเซ็นด้วย `license-private.pem` โปรแกรมไม่รับไฟล์ที่ลายเซ็นไม่ถูกต้อง

ผู้ดูแลออกอัปเดตด้วยคำสั่งนี้ แล้ว commit และ push

```bash
node tools/release.js 0.1.2
```

อัปเดตแบบนี้ครอบคลุมเฉพาะโฟลเดอร์ `desktop/` ส่วน `extension/` ต้องติดตั้งใหม่เอง
