ตอบแชท LINE OA ด้วยข้อความและรูปที่เตรียมไว้ กดปุ่มเดียว ข้อความพร้อมชื่อลูกค้าลงช่องแชทให้ ตั้งค่าครั้งเดียว ใช้เวลาราว 10 นาที

ส่วนที่ 1ติดตั้งโปรแกรม

ทำครั้งเดียวต่อเครื่อง

1

ดับเบิลคลิกไฟล์ QuickWai-Setup ที่ได้รับ

2

ถ้า Windows ขึ้นหน้าต่างสีฟ้า กด More info แล้วกด Run anyway

โปรแกรมป้องกันไวรัสบางตัวอาจเตือนหรือกักไฟล์ ถ้าติดตั้งไม่ได้ ให้แจ้งผู้ดูแล
3

โปรแกรมเปิดเอง ขึ้นหน้า ใส่โค้ดใช้งาน กด คัดลอกรหัสเครื่อง แล้วส่งรหัสพร้อมชื่อของคุณให้ผู้ดูแล

4

ผู้ดูแลส่งโค้ดกลับมา วางโค้ดในช่อง แล้วกด เริ่มใช้งาน

เข้าโปรแกรมได้แล้ว ป้ายมุมขวาบนยังเป็น "Extension ไม่ได้เชื่อมต่อ" ทำส่วนที่ 2 ต่อ

ส่วนที่ 2ติดตั้ง Extension ใน Chrome

Extension อ่านชื่อลูกค้าจากโน้ตใน LINE OA ติดตั้งครั้งเดียว หลังจากนั้นอัปเดตเอง

1

ในโปรแกรม QuickWai กดป้าย Extension ไม่ได้เชื่อมต่อ มุมขวาบน จะมีหน้าต่างบอกขั้นตอน เปิดค้างไว้

2

เปิด Chrome พิมพ์ chrome://extensions ในช่องที่อยู่ด้านบน กด Enter แล้วเปิดสวิตช์ Developer mode มุมขวาบน

3

กดปุ่ม Load unpacked ที่ขึ้นมาด้านซ้ายบน

Chrome ภาษาไทยใช้ชื่อ "โหลดส่วนขยายที่คลายการแพคแล้ว"

4

กลับไปที่หน้าต่างของ QuickWai กด คัดลอก หลังที่อยู่โฟลเดอร์ในข้อ 3

วางในช่องที่อยู่ด้านบนของหน้าต่างเลือกโฟลเดอร์ กด Enter แล้วกด Select Folder

ต้องเลือกโฟลเดอร์ชื่อ extension หน้าต่างจะดูว่างเปล่า ถูกแล้ว กด Select Folder ได้เลย ถ้าขึ้น "ไม่สามารถโหลดส่วนขยาย ไฟล์ Manifest หายไป" แปลว่าเลือกผิดโฟลเดอร์ ให้กดยกเลิกแล้วเลือกใหม่
5

เปิดหน้า LINE OA ถ้าเปิดอยู่แล้วให้กด F5 เปิดแชทลูกค้า แล้วเปิดแถบ โน้ต ด้านขวา

เตรียมโน้ตลูกค้า

ในแถบโน้ตของแชท เขียนคำว่า ชื่อ ตามด้วยชื่อลูกค้า หรือขึ้นต้นบรรทัดด้วย พี่ เช่น พี่บราวน์

โน้ต 1/1+
ชื่อ มายด์
QuickWai ใช้บรรทัดที่ขึ้นต้นด้วย "พี่" ก่อน เช่น พี่น้ำ ถ้าไม่มี จึงใช้คำที่ตามหลังคำว่า "ชื่อ" บรรทัด "ชื่อ - นามสกุล" เป็นชื่อในบัญชี โปรแกรมไม่ใช้เรียกลูกค้า โน้ตที่เขียนแค่ "มายด์" โปรแกรมจะไม่พบชื่อ

ใส่แท็ก และดูป้ายเตือนบนหน้าแชท

ทุกแชทต้องมี 2 อย่างก่อนตอบ: โน้ตชื่อลูกค้า และแท็ก QuickWai ขึ้นป้ายมุมขวาบนของช่องแชทให้เห็นว่าขาดอะไร

  • ลากป้ายไปวางตรงไหนก็ได้

สร้าง Reply

1

กด + เพิ่ม Reply ใส่ชื่อ Reply และเลือกหมวด

2

คลิกช่อง Hotkey แล้วกดปุ่มที่ต้องการ เช่น Alt + 4

3

พิมพ์ข้อความ ตรงที่ต้องการชื่อลูกค้า กด แทรก {ชื่อ} ต้องการส่งรูปด้วย กด + เพิ่มรูป ใส่ได้หลายรูป แล้วกด บันทึก

หลายชุดข้อความใน Hotkey เดียว

Reply 1 อันใส่ข้อความได้หลายชุด เหมาะกับเรื่องเดียวกันที่มีคำตอบหลายแบบ

  • ในหน้าแก้ไข Reply กด + เพิ่มชุดข้อความ แต่ละชุดมีข้อความและรูปของตัวเอง
  • กด "↑ ขึ้น" "↓ ลง" เพื่อเรียงลำดับ ลำดับนี้คือเลขที่ใช้กดตอนตอบ
  • ตอนตอบ กด Hotkey จะขึ้นรายการชุดข้อความ กดเลข 1 ถึง 9 เพื่อวางทันที หรือกดลูกศรแล้ว Enter

ตอบลูกค้า

1

เปิดแชทลูกค้าใน LINE OA ไม่ต้องคลิกช่องพิมพ์ข้อความ โปรแกรมย้ายเคอร์เซอร์ไปให้เอง

2

กด Hotkey ของ Reply เช่น Alt + 1 ข้อความพร้อมชื่อลูกค้าลงช่องพิมพ์ให้

3

ตรวจข้อความ แล้วกด Enter เพื่อส่ง

ถ้า Reply มีรูป LINE จะถามยืนยัน กด ส่ง

ยกเลิก ส่ง

จำ Hotkey ไม่ได้ ใช้ค้นหาด่วน

แถบบนขึ้น "ไม่พบชื่อในโน๊ต" ยังส่งได้ตามปกติ โปรแกรมตัดคำว่า {ชื่อ} ออกให้ ข้อความจะไม่มีชื่อลูกค้า

เรื่องที่ควรรู้

  • Hotkey ของ Reply ใช้ได้เฉพาะตอนหน้าแชท LINE OA อยู่ด้านหน้า
  • กดกากบาทปิดหน้าต่าง โปรแกรมยังทำงานอยู่ ไอคอนอยู่มุมขวาล่างของจอ
  • โปรแกรมเปิดเองตอนเปิดเครื่อง ปิดได้ที่ ตั้งค่าและข้อมูล
  • โปรแกรมอัปเดตเอง ต้องการอัปเดตทันที กด ตั้งค่าและข้อมูล แล้วกด ตรวจอัปเดต โปรแกรมจะเปิดใหม่เอง
  • โค้ดใช้งานมีวันหมดอายุ 7 วันสุดท้ายมีแถบสีเหลืองเตือน ส่งรหัสเครื่องให้ผู้ดูแลเพื่อขอโค้ดใหม่
  • ส่งชุด Reply ให้เพื่อนได้ กด ส่งออก เพื่อนกด นำเข้า

แก้ปัญหา

อาการวิธีแก้
ป้ายขึ้น "Extension ไม่ได้เชื่อมต่อ"เปิดหน้า LINE OA แล้วกด F5 ถ้ายังไม่ขึ้น ตรวจว่า Extension เปิดอยู่ในหน้า chrome://extensions
Chrome ขึ้น "ไม่สามารถโหลดส่วนขยาย ไฟล์ Manifest หายไป"เลือกผิดโฟลเดอร์ กดยกเลิก กด Load unpacked ใหม่ แล้วเลือกโฟลเดอร์ชื่อ extension
ขึ้น "ไม่พบแถบโน้ต"เปิดแถบโน้ตด้านขวาของแชท ถ้ายังไม่พบ กดไอคอน QuickWai บนแถบ Chrome กด "เลือกแถบโน้ตเอง" แล้วคลิกที่แถบโน้ต
ขึ้น "ไม่พบชื่อในโน๊ต"ตรวจว่าโน้ตมีบรรทัดขึ้นต้นด้วย "พี่" เช่น พี่น้ำ หรือมีคำว่า "ชื่อ" นำหน้า เช่น ชื่อ มายด์
กด Hotkey แล้วไม่มีอะไรเกิดขึ้นคลิกช่องพิมพ์ข้อความในแชทก่อน และตรวจว่าป้าย Extension เป็นสีเขียว
ขึ้น "วางไม่สำเร็จ"ข้อความอยู่ใน Clipboard แล้ว คลิกช่องพิมพ์ข้อความ กด Ctrl + V
ใช้ Incognito แล้วชื่อไม่ขึ้นเปิดสวิตช์ Allow in Incognito ตามส่วนที่ 2
