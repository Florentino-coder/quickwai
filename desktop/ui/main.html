ติดตั้ง Extension ใน Chrome

ทำ 4 ขั้น ครั้งเดียว ราว 2 นาที หลังจากนั้น Extension อัปเดตตามโปรแกรมเอง

1
เปิดหน้าส่วนขยายของ Chrome

กด คัดลอก แล้วเปิด Chrome วางในช่องที่อยู่ด้านบน กด Enter

chrome://extensions
2
เปิดสวิตช์ Developer mode

อยู่มุมขวาบนของหน้านั้น กด 1 ครั้งให้เป็นสีฟ้า

Chrome ภาษาไทย: โหมดนักพัฒนาซอฟต์แวร์

3
กด Load unpacked แล้วเลือกโฟลเดอร์

กด คัดลอก วางในช่องยาวบนสุดของหน้าต่างเลือกโฟลเดอร์ กด Enter แล้วกด Select Folder

Chrome ภาษาไทย: โหลดส่วนขยายที่คลายการแพคแล้ว

หน้าต่างดูว่างเปล่า ถูกแล้ว กด Select Folder ได้เลย
4
เปิดหน้า LINE OA แล้วกด F5

เปิดแชทลูกค้า 1 คน ป้ายด้านบนเปลี่ยนเป็นสีเขียว = เสร็จ

ใช้ Chrome ไม่ระบุตัวตน

ในหน้า chrome://extensions กด "รายละเอียด" (Details) ของ QuickWai Note Reader แล้วเปิด "อนุญาตในโหมดไม่ระบุตัวตน" (Allow in Incognito)
