เวอร์ชัน Extension เปิดพร้อม Windows เปิดเมื่อ

ติดตั้ง Extension ใน Chrome

  1. เปิด Chrome แล้ววาง chrome://extensions ในช่องที่อยู่
  2. เปิดสวิตช์ โหมดนักพัฒนาซอฟต์แวร์ (Developer mode) มุมขวาบน
  3. กด โหลดส่วนขยายที่คลายการแพคแล้ว (Load unpacked) แล้วเลือกโฟลเดอร์นี้
  4. เปิดหรือรีเฟรชหน้า chat.line.biz แล้วเปิดแถบโน้ตด้านข้างของแชท
  5. สถานะด้านบนต้องเปลี่ยนเป็น "Extension เชื่อมต่อแล้ว"

ติดตั้งครั้งเดียว หลังจากนั้น Extension อัปเดตตามโปรแกรมเอง

ใช้ Chrome ไม่ระบุตัวตน: ในหน้า chrome://extensions กด "รายละเอียด" ของ QuickWai Note Reader แล้วเปิด "อนุญาตในโหมดไม่ระบุตัวตน"

เชื่อมต่อแล้วแต่ไม่พบชื่อ: กดไอคอน QuickWai บนแถบ Chrome กด "เลือกแถบโน้ตเอง" แล้วคลิกที่แถบโน้ตในหน้าแชท
